# Security policy

Status: **draft**.

## Report a vulnerability

Use the private GitHub
[Report a vulnerability form](https://github.com/Alberto-Codes/typevet/security/advisories/new).
Sign in to GitHub to submit a report. Do not put a vulnerability, a key or
private data in a public issue.

Include the affected version, the impact and a minimal reproduction. Use
dummy keys and synthetic data.

## Supported versions

Reports apply to the latest release on PyPI. This policy does not promise a
response deadline or fixes for older releases.

## Data, keys and redaction

The [security reference](https://alberto-codes.github.io/typevet/reference/security/)
lists the data that typevet sends to a backend.
It also covers API key masking and redaction in diagnostic events.
